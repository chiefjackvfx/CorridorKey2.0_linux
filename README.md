# CorridorKey 2.0

I'm working on getting CorridorKey 2.0 running on Linux with a desktop UI,
automatic key previews, and an integrated hint editor. I've also added optional
SAM 3.1 support to generate masks inside the app, with text prompts, point and
box selections, and brush corrections.

Huge thanks to Niko, Zachary Harris, and the whole Corridor Digital team for
developing CK2 and sharing it with the community. Thanks also to
[edenaion](https://github.com/edenaion) for
[EZ-CorridorKey](https://github.com/edenaion/EZ-CorridorKey), which inspired the
Linux UI and workflow. This fork is a work in progress; the original README
continues below.

**Linux and Windows setup, repair, and updates:** see [SETUP.md](SETUP.md).
Windows GPU validation is still pending.

**Local Linux desktop edition:** see [LINUX.md](LINUX.md) for installation,
the desktop job queue, troubleshooting, and validation. Start with `./2-start.sh`
after running `./1-install.sh`. The upstream instructions follow below.

Welcome to CorridorKey 2.0! You may rest easy, weary artist. The green beast has been slain. The CorridorKey 2.0 model was designed and trained by Zachary Harris, in direct collaboration with Niko and Corridor Digital.
